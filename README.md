# Орден Дельти

Фізичний роглайк для студентів. Замок паладинів, сучасні майстри-герої, зали з підказками і двері, що відчиняються лише правильною відповіддю.

Гра: **https://phys-kpkb.github.io/delta/** (працює після кроку «Увімкнути сайт» нижче).

Все генерується прямо в браузері: піксель-арт малюється кодом на canvas, музика й звуки синтезуються через Web Audio. Ні картинок, ні аудіофайлів, ні збірки.

## Як грати

1. При першому заході обираєш групу, себе зі списку (бажано, для рейтингу) і вводиш нік (обов'язково). Списки беруться з репозиторію [gamma](https://github.com/phys-kpkb/gamma) (`data.json`).
2. Обираєш героя: Столяр, Радіоелектронік, Зварювальник-Муляр або Маляр-Штукатур, «він» чи «вона».
3. Обираєш рівень і ходиш замком дотиками: куди торкнешся, туди й іде герой.
4. Предмети, що поблискують, це підказки: формули, означення й числа для задач.
5. Двері ставлять питання. Після кожних відчинених дверей обираєш бонус.
6. Таймер іде від першого залу до печаті Паладина. Результат потрапляє в рейтинг.

### Рівень I · Механіка (5 залів)

| Зал | Тема | Двері |
|---|---|---|
| Вартова брама | швидкість `v = s/t` | Дубові: помилка +30 с, ключ відчиняє |
| Стайня | км/год → м/с | Залізні ґрати: лише правильна відповідь, без штрафу, ключ безсилий |
| Кузня | прискорення `a = (v − v₀)/t` | Двері терпіння: +20 с за помилку, після 3 помилок можна пройти за +60 с |
| Бібліотека | графіки v(t), шлях як площа | Двері мудреця: 2 питання, але друге пропускається, якщо на перше відповів з першої спроби |
| Тронна зала | `v = at`, `s = at²/2` | Печать Паладина: 3 питання поспіль, +30 с за помилку |

Числа в задачах генеруються для кожного забігу окремо, тож відповідь сусіда не підійде. Підказки в кімнаті показують саме твої числа.

### Герої

- **Столяр**: починає забіг із ключем від дубових дверей.
- **Радіоелектронік**: у питаннях з вибором одна хибна відповідь гасне одразу, а на числових після помилки видно «тепло / холодно».
- **Зварювальник-Муляр**: штрафи вдвічі менші, а ще він розбирає тріснуті стіни, за якими сховані скрині з бонусами.
- **Маляр-Штукатур**: відновлює вицвілі фрески з додатковими підказками.

### Бонуси

Ключ, Щит паладина (наступна помилка без штрафу), Сувій мудреця (показує, як рахувати, з твоїми числами), Пісочний годинник (−20 с), Чоботи-скороходи (ходиш удвічі швидше).

## Увімкнути сайт (GitHub Pages)

1. Репозиторій `delta` → **Settings** → **Pages**.
2. **Build and deployment** → Source: **Deploy from a branch**.
3. Branch: гілка з грою (зараз `claude/busy-tesla-91n7qk`, після злиття `main`), папка `/ (root)` → **Save**.
4. Через 1–2 хвилини гра відкриється за адресою https://phys-kpkb.github.io/delta/

## Рейтинг у Google Таблиці

Студенти не мають GitHub-токенів, тому результати пишуться в Google Таблицю через маленький скрипт. Поки скрипт не підключено, рейтинг працює тільки локально на пристрої гравця.

1. Створіть нову таблицю: https://sheets.new (наприклад, «Орден Дельти: рейтинг»).
2. У таблиці: **Розширення → Apps Script**.
3. Видаліть усе в редакторі, вставте вміст файлу [`apps-script/Code.gs`](apps-script/Code.gs) і натисніть 💾 **Зберегти**.
4. Праворуч угорі **Розгорнути → Нове розгортання**.
   - Тип (шестерня): **Вебзастосунок**.
   - Опис: `рейтинг`.
   - Виконувати як: **Я**.
   - Хто має доступ: **Усі** (Anyone).
   - **Розгорнути**.
5. Google попросить дозвіл: оберіть свій акаунт → **Додатково** → **Перейти до проєкту (небезпечно)** → **Дозволити**. Попередження стандартне, бо це ваш власний неперевірений скрипт.
6. Скопіюйте **URL вебзастосунку** (закінчується на `/exec`).
7. Перевірка: відкрийте в браузері `ВАШ_URL?action=top&level=1`. Має з'явитися `{"ok":true,"level":1,"rows":[]}`.
8. Відкрийте [`js/config.js`](js/config.js) і вставте URL у `RATING_URL: '…/exec'`, потім закомітьте зміну (або просто надішліть URL Claude).

Результати з'являтимуться на листі **«Результати»**: кожна спроба окремим рядком (нік, група, студент, час, помилки, штрафи, герой). У грі рейтинг показує найкращий час кожного гравця і кількість спроб, з фільтром за групою.

Якщо потім змінюєте код скрипта: **Розгорнути → Керувати розгортаннями → ✏️ → Версія: нова → Розгорнути**. URL не зміниться.

> Чесно про захист: це клієнтська гра, тож технічно підкований студент може надіслати фальшивий час. Скрипт відсікає очевидне (менше 20 с, дублікати, формули в ніку), а всі спроби видно в таблиці, тож підозріле легко помітити й видалити рядок.

## Структура

```
index.html          оболонка, вкладки «Рівні» / «Рейтинг», екран гри
css/style.css       чорно-золотий дизайн, mobile-first
js/app.js           екрани, профіль, вибір героя, двері, бонуси, перемога, рейтинг
js/game.js          рушій кімнати: рендер, світло, ходьба кліками (BFS)
js/art.js           весь піксель-арт (спрайти, персонажі, іконки)
js/audio.js         генеративна музика й звуки (Web Audio)
js/levels.js        рівні, кімнати, задачі, типи дверей, бонуси
js/net.js           групи з gamma, відправка й читання рейтингу
js/config.js        URL рейтингу та джерела груп
apps-script/Code.gs скрипт для Google Таблиці
```

Новий рівень — це новий об'єкт у `LEVELS` у `js/levels.js`: карта 9×13, предмети-підказки, двері з питаннями і функція `params(rng)`, яка генерує числа.
